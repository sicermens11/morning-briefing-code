# 판정 장치 전수조사 — 맹점이 어디 있나

**2026-09-20 · 사용자 「4관문은 확실한거야? 맹점 없어?」 「반영 기각을 판단하는 테스트들 맹점 헛점 한번 점검해야 하는 거 아니야? 전수조사?」**

우리가 「반영한다 / 기각한다」를 정하는 곳을 **전부** 찾아 하나씩 따졌다.
결론부터: **판정 장치가 두 벌로 갈라져 있고, 둘 다 새는 곳이 있다.**

---

## 0. 판정 장치가 **두 벌**이다 (이것부터가 맹점)

| | 어디 | 무엇으로 재나 | 무엇을 지나야 하나 |
|---|---|---|---|
| **옛 4관문** | `gate7_lab.py` 1578~1690줄 · `통과표` | **이길 확률**(20일 뒤 오른 비율) | A 앞뒤 분할 · B 해마다 · C 무작위 대조 |
| **새 판정** | 절마다 손으로 (`_ok = (...)`) | **돈**(자본 시뮬) | 셋 다(산 것↑·돈↑·낙폭 −10% 안) + 해마다 + 걷기 |

기억에 [[avg-return-is-not-money]]·[[walkforward-must-use-capital-sim]] 가 있는데도
**옛 4관문은 여전히 이길 확률로만 판정한다.** 화면 맨 끝 「판정 — A·B·C 를 다 지나야」 표가 그것이다.
돈으로 재는 새 판정은 절마다 `_ok = (...)` 를 손으로 적어 놓아 **한 곳에 모여 있지 않다.**

> ⇒ 같은 후보가 옛 표에서는 「통과」, 새 절에서는 「탈락」으로 찍힐 수 있다. 실제로 그런 줄이 있다.

---

## 1. 새 판정 — 「셋 다」

```python
_ok = (r["산"] > 기["산"], r["끝"] > 기["끝"], r["낙"] > -10.0)
```

| 조건 | 맹점 |
|---|---|
| `산 것 >` | **+1건이면 통과.** 문턱이 없다 |
| `돈 >` | **+1원이면 통과.** 문턱이 없다 |
| `낙폭 > -10.0` | **벼랑.** −9.9는 통과, −10.1은 탈락. 이 숫자의 **근거가 기록에 없다** |

앞의 둘은 **너무 헐겁고**(잡음이 그대로 통과), 뒤의 하나는 **너무 딱딱하다**(0.2%p 차이로 갈림).
9/20 Ⓗ 가 −11.0% 라 **이 한 숫자에 지금 규칙 자체가 걸려 있다.**

---

## 2. 새 판정 — 해마다

```python
_승[0 if _d > 1 else 1 if _d < -1 else 2] += 1   # 이김 > 짐 이면 ✅
```

**잴 힘이 없다.** 9/20 후보 넷을 실제로 따져본 값:

| 후보 | 해마다 돈차이 평균 | 평균의 오차 | t |
|---|---|---|---|
| (−5,−13) | −0.77% | ±1.71% | −0.45 |
| (−5,−16) | −1.48% | ±1.88% | −0.79 |
| (−6,−13) | **+0.23%** | ±1.59% | +0.14 |
| (−6,−16) | −0.45% | ±1.58% | −0.28 |

t 가 전부 |t| < 1 이다. **「나쁘다」가 아니라 「해마다로는 못 가른다」**이다.
한 해 시뮬이 거래 30건쯤이라 해마다 ±5~6% 씩 널뛴다. 11년으로 3% 차이를 가리려면 턱없다.

**죽은 구간 ±1% 도 결과를 만든다:**

| 죽은 구간 | (−5,−13) |
|---|---|
| ±0% | 4승 6패 |
| **±1% (지금)** | **4승 5패** |
| ±2% | 4승 4패 (무승부) |

⇒ 내가 고른 선 하나로 승패가 갈린다. 숫자가 아니라 선택이다.

---

## 3. 새 판정 — 걷기 앞뒤 · **낙폭을 아무도 안 센다**

해마다도 걷기도 **돈만** 본다.
전체 기간에서 낙폭이 −11.0% → −6.7% 로 좋아진 것이 **두 관문에서 한 번도 안 세어진다.**

⚠️ 다만 9/20 후보들은 **낙폭을 넣어도 통과 못 한다** — 해마다 낙폭이
나아진 해 2번 · 나빠진 해 5번 · 평균 −0.45%p 였다.
전체 낙폭이 좋아진 건 **어느 한 해의 최악 구간**이 얕아진 것이지 고르게 나아진 게 아니다.

---

## 4. 옛 4관문 — C 무작위 대조가 **너무 헐겁다**

```python
든다 = 상위 <= 25
```

**무작위로도 4개 중 1개가 통과한다.** 조합을 수백 개 훑는 판에서 상위 25% 문턱은
거르개 구실을 거의 못 한다. 200번 뽑아 분포를 내놓고 문턱만 헐겁다.

## 5. 옛 4관문 — B 해마다도 같은 병

```python
if 차 > 0.5: 이김 += 1
elif 차 < -0.5: 짐 += 1
```
죽은 구간 ±0.5%p · 승패 세기 · 유의성 없음. 1·2번과 같은 맹점이다.

## 6. 옛 4관문 — A 앞뒤 분할

「네 구간 전부 낫다」. 효과가 없어도 **1/16 확률로 그냥 통과**한다.
다만 넷을 다 요구하므로 셋 중에서는 제일 빡빡하다.

## 7. 그 밖에 찾은 것

| 곳 | 맹점 |
|---|---|
| 표본 바닥 | 절마다 500 / 2,000 / 20,000 / 50,000 으로 **다르다**. 같은 칸이 절에 따라 재지거나 안 재진다 |
| 조합 훑기 | 수백 조합을 훑고 「제일 센 것」을 고른다. **여러 번 본 것을 보정하지 않는다** |
| 판정표 읽기 | 파일 **이름**으로 찾았다 → 이름이 바뀐 9/19 부터 이틀간 못 읽었다 (9/20 고침) |
| 기간 | 2010~2026. **한 시장, 한 나라, 16년.** 걷기 나누기는 **단 한 번**뿐이라 앞뒤 각각 표본 1개다 |

## 고칠 것 — 사용자 승인 (2026-09-20)

   「평균 −0.8% ± 1.7% · t −0.45 · **구별 안 됨**」으로 적는다

덤으로 같이 고치는 것 (같은 병이라):
