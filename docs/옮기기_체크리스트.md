## 2. 맥으로 옮길 때 — 그대로는 안 돈다

| 걸리는 것 | 지금 | 규모 | 맥에서 |
|---|---|---|---|
| 대기열·게시 스크립트 | PowerShell 5.1 (`.ps1`) | **270개** | 맥엔 Windows PowerShell 이 없다 (pwsh 는 있지만 아래 줄들이 안 돈다) |
| 메모리·프로세스 검사 | `Get-CimInstance Win32_OperatingSystem` · `Win32_Process` | 200여 파일 | 맥엔 없음 → 파이썬 `psutil` 로 바꿔야 |
| 경로 | `C:\Users\mrblue\…` · `…\Python313\python.exe` 손으로 박음 | 260여 파일 | 맥 경로(`/Users/…`)로 — 설정 한 곳에서 읽게 바꿔야 |
| 예약 | 작업 스케줄러 22개 | | `launchd`(맥) 로 다시 · **노트북은 잠들면 안 돈다**(08:00 브리핑) |
| 메모리 | 판 하나 7~24GB · 커밋 한도 47.9GB | | 맥 메모리가 16GB 면 큰 판(시장 전체·중형)이 못 돈다 |
| 화면 검사 | 크롬 경로 (check_layout) | | 맥 크롬 경로로 |
| 글자 | cp949·BOM 대비 코드 | | 맥은 UTF-8 이라 오히려 편하다 |

**권고**: 맥 노트북은 「결과 보기·화면 확인·대화」 용으로, 판(시험)과 08:00 브리핑은 **늘 켜 두는 PC** 에서 — 노트북은 잠들고 메모리가 작다.
정말 맥으로 다 옮기려면 순서: ① 경로를 설정 파일 하나로 모으기 ② 메모리·프로세스 검사를 psutil 로 ③ 대기열을 파이썬으로 다시 (가장 크다) ④ launchd 예약. **옮길 날이 정해지면 그때 한다** — 지금 바꾸면 돌고 있는 판을 깰 수 있다.
