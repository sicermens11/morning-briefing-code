# 가진 자료 재고

`python scripts/data_stock.py --md docs/자료재고.md` 가 만든 것. **하위 폴더까지 내려가** 파일을 열어 센 값이다.

> ⚠️ 규모 칸의 숫자는 **전부 실측**이다. 한계 칸에는 숫자를 적지 마라 — 09-07에 손으로 적어 둔 숫자가 얼어붙어 일주일 동안 거짓말을 했다.
