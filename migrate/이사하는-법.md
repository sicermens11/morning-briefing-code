## 2. ⚠️⚠️ 안 따라오는 것 셋 — 새 PC에서 다시 해야 한다

### ① 작업 스케줄러 (매일 08:00 실행)
설정을 `migrate\*.xml`로 빼놨다. 새 PC에서 **관리자 PowerShell**로:
```powershell
Register-ScheduledTask -Xml (Get-Content "migrate\MorningSectorBriefing.xml" -Raw) -TaskName "MorningSectorBriefing"
Register-ScheduledTask -Xml (Get-Content "migrate\ValueChainMapUpdater.xml"  -Raw) -TaskName "ValueChainMapUpdater"
```
⚠️ XML 안에 **경로와 계정 이름이 박혀 있다.** 경로가 바뀌면 열어서 고친 뒤 등록한다.

### ② 실행 환경
`Python` · `Chrome`(카드 검사기가 쓴다) · `git` · `Claude Code`. 새로 설치한다.

### ③ MCP 커넥터 (Gmail·Drive·Notion 등)
**PC가 아니라 claude.ai 계정에 붙어 있다.** 로그인만 하면 그대로 따라온다. 할 일 없다.
GitHub Pages 저장소도 마찬가지로 계정 것이다.

## 3. ⚠️⚠️⚠️ 퇴사 전에 반드시 — 열쇠를 지우고 다시 받는다

`data\secrets.json`에 **다섯 개**가 들어 있다:
```
DART_API_KEY        공공 데이터. 읽기만 한다
KRX_API_KEY         공공 데이터. 읽기만 한다
GITHUB_TOKEN        ⚠️ 저장소에 글을 쓸 수 있다
NHPLUG_APP_KEY      ⚠️⚠️ 증권 계좌다
NHPLUG_APP_SECRET   ⚠️⚠️ 증권 계좌다
```

**회사 PC를 반납하기 전에:**
1. `data\secrets.json`을 **지운다** (휴지통 말고 완전 삭제)
2. **NHPLUG 두 개를 재발급한다** — 계좌 열쇠가 회사 장비에 남아 있었다
3. **GITHUB_TOKEN을 재발급한다** — 저장소 쓰기 권한이다
4. DART·KRX는 공공 데이터 읽기 전용이라 급하지 않다.
   ⚠️ 단 **DART는 약관상 스스로 재발급이 안 된다**(2026-08-31 확인). 그냥 둔다.

⚠️ **열쇠를 채팅에 붙여넣지 않는다 — 대화 기록에 남는다.**
확인은 `python scripts\check_secrets.py`로 한다. 이름과 길이만 찍는다.

## 4. 경로가 바뀌면 고칠 곳

새 PC의 사용자 이름이 `mrblue`가 아니거나 폴더 위치가 다르면:
```
migrate\*.xml              작업 스케줄러 안의 경로·계정
스킬 안의 절대경로          C:\Users\mrblue\.claude\skills\ 아래를 grep 한다
data\secrets.json 경로      스크립트가 프로젝트 기준 상대경로라 대개 괜찮다
```
확인은 이걸로 한다:
```
grep -rn "C:\\Users\\mrblue" scripts/ ~/.claude/skills/
```
