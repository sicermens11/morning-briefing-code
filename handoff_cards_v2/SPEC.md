## 1. 카드 래퍼 — `section[data-label]` 유지 (게시 차단 위험)

참조 구현은 미리보기 편의상 `<div data-screen-label="01 커버">`를 씁니다. **프로덕션은 지금 형식을 그대로 유지하십시오.**

```html
<section data-label="01 커버"> ... </section>
```

바꾸면 세 곳이 깨집니다 — `check_layout`·`tune_budget`의 `querySelectorAll("section[data-label]")`, `build_site`의 `.rail section` 배율·스와이프. 특히 **check_layout이 카드를 0개 찾고도 "실패 0건"으로 통과**하므로, 전 카드가 잘려도 게시됩니다.

## 2. 배경 — 4겹 (아래에서 위로) · **사진 사용 안 함**

- 배경 사진은 **쓰지 않기로 결정**했습니다(블러가 강해 무엇을 찍었는지 알 수 없고, 보도사진 라이선스 문제). mesh + 오버레이 + 노이즈만으로 완결됩니다.
- **`backdrop-filter`는 쓰지 않습니다.** 헤드리스 크롬 스크린샷에서 무시돼 유리 효과가 사라지고 대비가 무너집니다 — 참조 구현에서 8곳 전부 제거했습니다.

## 3. 카드 구조

```
section[data-label]  (1080×1350, overflow:hidden, position:relative, background:#1a1b1d, flex:none)
├ 배경 5겹 (2절)
└ inner  position:relative; height:100%; box-sizing:border-box;
         display:flex; flex-direction:column; padding/gap 아래 표
   ├ 헤더 행: 색 점(11px) + 섹션명 + 1px 헤어라인 + 쪽번호
   ├ 제목: 46~62px / 700 / letter-spacing -.04em / line-height 1.18
   ├ 히어로 블록: 그 섹션의 핵심 수치
```

## 4. 컴포넌트

### 카드(패널)
```css
background: rgba(255,255,255,.06);          /* 주요 패널 */
border: 1px solid rgba(255,255,255,.09);
border-radius: 26px;
padding: 24~34px;
/* box-shadow 없음, backdrop-filter 없음 */
```
보조 패널은 `rgba(255,255,255,.04)` + `border .08`. 내부 소형 칸은 `rgba(255,255,255,.04)`, `radius 18px`, 패딩 20px.

### 지수 3개 (02장)
세 지수는 성격이 같으므로 **같은 크기 3열 그리드**(`gap:14px`)로 둡니다. 각 칸: 이름 26px 회색 / 값 44px 700 / 변동률 28px 700(부호색). 하나만 크게 잡지 마십시오.

### 등급 pill (이모지 대체)
🔴🟢🟡 이모지는 쓰지 않습니다. `padding:12px 20px; border-radius:999px;` + 점(11px) + 라벨(26px/700).

| 등급 | 점·보더 | 라벨 |
| --- | --- | --- |
| 최우선매수 | `#e0776c` | `#e0776c` |
| 주목 | `#12d6b0` | `#12d6b0` |
| 점검 | `#c9a227` | `#e0bd52` |

등급 색은 **등락 색과 별개**입니다(등급은 판정, 등락은 가격).

### 긍정/부정 신호
왼쪽 4px 세로 바(긍정 `#12d6b0` / 부정 `#e0776c`) + 라벨 26px/700 + 본문 26px/1.55.

### 확인·손절·발굴
3열 그리드 `gap:14px`. 라벨 26px 회색 + 값 26px/700 (확인 민트 / 손절 로즈 / 발굴 흰색). **이 세 값은 등락이 아니므로 빨강/파랑 규칙을 적용하지 않습니다.**
**7자리 금액 내성 필수** — `2,759,000원`이 한 칸(≈287px)에 들어가야 합니다. 세 값을 한 줄에 이어 붙이지 마십시오.

### 국면 게이지
6~9px 바, `linear-gradient(90deg,#1b3bf0,#12d6b0 46%,#c9a227)`, 흰 원형 핸들 23px + `box-shadow: 0 0 0 6px rgba(10,11,13,.9)`. 아래 눌림/평균/과열 라벨 26px.

### 섹터 칩
`padding:16px 22px; radius:16px;` **부호색 10% 배경 + 24% 보더 + 부호색 텍스트**. 이름과 등락률을 `space-between`으로 양끝 정렬. 상승 칩은 빨강 계열이어야 합니다(민트 배경 + 빨강 글자 조합 금지).

두 곳에 사는 것**입니다 — 나중에 한쪽만 고치면 조용히 갈라집니다(국면 라벨에서 겪고
`band_color`를 공유로 만든 그 버그와 같은 종류).

**그래서 이렇게 막습니다.**
1. `card_theme_v2`는 **hex 값만** 갖습니다. 「양수면 상승, 음수면 하락」이라는 판단은
   `card_theme.sign_color`의 구조를 그대로 씁니다. 규칙은 한 곳, 값만 두 곳.
2. `check_layout`에 **자동 대조**를 붙입니다 — v2의 상승 색이 정말 빨강 계열인지(R>B),
   하락이 파랑 계열인지(B>R). 누가 민트로 바꿔놔도 그날 걸립니다.
   (`whatif_grades.py`가 `SKILL.md`의 등급 컷오프를 읽어 대조하는 것과 같은 방식입니다.)

같이 줄여야 한다** — 안 줄이면 넘쳐서 게시가 막히는 날이 늘어난다. 7절 10번 참조.

글꼴: **Pretendard 하나만.** 고정폭(mono) 금지 — 한글이 폴백으로 튀어 한 낱말 안에서 글꼴이 갈리고 `check_layout`이 치명 실패를 냅니다. 숫자 자리 맞춤은 최상위 컨테이너의 `font-variant-numeric: tabular-nums`가 담당합니다. 참조 구현에 mono 참조는 0건입니다.

## 7. 필수 검증 조건

1. **모든 카드 `scrollHeight === clientHeight === 1350`**, 그리고 **`offsetWidth === 1080`**(`flex:none` 확인). 넘치면 잘립니다.
2. **28px 미만 글꼴 0건.**
3. **mono 글꼴 0건.**
4. **액션플랜은 최대 2장이고, 후보 수만큼 냅니다.** 후보가 3개 이상이어도 카드에는 2개만 싣고, 나머지는 세로 상세로 넘깁니다("오늘 후보 N종목 중 둘만 실었습니다" 문구 유지).
   ⚠️⚠️ **후보 1개면 액션 카드도 1장입니다.** 「2장 고정」으로 읽어 둘째 장을 비우면,
   5번이 금지한 빈 카드가 그대로 나옵니다. 실측 39일 분포다 —
   **후보 0개 3일(8%) · 1개 8일(21%) · 2개 24일(62%) · 3개 이상 4일(10%).**
   즉 **다섯 날 중 하루가 후보 1개**다. 제일 흔한 예외이니 반드시 렌더해서 확인하십시오.
   총 장수는 후보 수에 따라 매일 바뀝니다(7~8장). 쪽번호는 번호만 찍고 총 장수는 안 찍습니다.
5. **후보 0종목 → 상태 카드 1장** (11절). 빈 액션 카드를 내지 마십시오.
6. **긴 종목명** — `LIG디펜스앤에어로스페이스`(13자)가 40px에서 들어가야 합니다. `white-space:nowrap`을 새 디자인에 옮기지 말고 줄바꿈 허용 + `text-wrap:pretty`.
7. **7자리 금액** — 4절 참조.
8. **배경 레이어는 모두 `pointer-events:none`** (2절).
9. `check_layout`의 여백 기준(90px)은 이 디자인에서 패딩이 38~52px로 줄었으므로 **하단 여백 기준으로 다시 산정**하고 근거를 남기십시오.
   ⚠️ **액션 카드부터 재십시오 — 거기가 제일 빡빡합니다.** 지금 카드 실측 아래 여백은
   커버 176 · 뉴스 191 · 국면 146~205 · **액션 114~120px**입니다. 액션이 최소치입니다.
   ⚠️⚠️ **하한을 낮추면 「넘쳐서 게시가 막히는 날」이 늘어납니다.** `first_sentence()`는
   첫 문장을 절대 자르지 않고(자르느니 넘치게 두고 `check_layout`이 막게 하는 설계),
   웹 게시는 이미 실측 2회 중 1회 막힌 전례가 있습니다. 하한을 얼마나 낮출지는
   **"몇 줄까지 늘어나도 버티나"로 환산해서** 근거를 대십시오.
10. `tune_budget` 예산 재산정 — 본문 27px·line-height 1.6 기준 한 줄 ≈ 30자.
    ⚠️ **`build_cards.CUT`을 바꾸면 `SKILL.md`도 같이 고쳐야 합니다.** 같은 숫자가 스킬
    **1707·1835줄**에 글로 박혀 있습니다. 한쪽만 고치면 모델이 옛 상한에 맞춰 글을 씁니다.
