**「하겠습니다」를 마지막 줄에 쓰고 턴을 끝내면 그 일은 안 된다.** 메시지 경계가 약속의 무덤이다.

**Why:** 2026-09-15 하루에 두 번.
- 「빠진 뒤 장중 공시 — **다음 판으로 걸겠습니다**」 → 안 걸었다. 사용자: 「자본시뮬 돌리고 있는 거지?」 → 「안 돌고 있습니다」
- 「㉥㉦㉧ **셋 다 지금 하겠습니다**」 → 표만 그리고 턴을 끝냈다.
  사용자: 「셋 다 지금 한다고 했으면 테스트에 반영된 거야? **왜 자꾸 반복되는 거지?**」

둘 다 같은 모양이다 — **진단·표·계획을 길게 쓰고 실행은 다음 턴으로 미뤘다.** 다음 턴은 사용자 질문으로 시작되니 미룬 일은 잊힌다.

**How to apply:**
- 할 일이 정해졌으면 **그 턴 안에서 건다.** 설명은 걸고 나서 쓴다
- 보고는 「하겠다」가 아니라 **로그 줄**(`09-15 16:52 [V] 시작`)이나 커밋 해시로 한다
- 긴 진단을 쓰고 있으면 멈추고 묻는다 — 「이 진단이 끝나면 **내가 무엇을 실행하나**?」 그걸 먼저 한다
- 여러 개면 **싼 것부터 즉시**(문서 고침 → 코드 → 줄 세우기). 하나라도 걸어 놓고 나머지를 쓴다
- [[measure-then-carry-through]] 와 [[report-fix-with-problem]] 의 실행 쪽 규칙이다
