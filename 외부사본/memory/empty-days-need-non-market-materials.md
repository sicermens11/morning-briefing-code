**Ⓗ(지금 규칙) 위에 OR 로 얹어 돈이 늘려면 「Ⓗ 가 안 사던 날」에 떠야 한다. 시장 눌림 재료로 만든 칸은 거의 다 새 날 0 이다.**

**Why (2026-09-22 밤 · Q-30 다섯 판, 25칸):**
- 코스피200선물20↓·시장낙폭↓ 로 만든 칸(초소형·소형·중형·대형 대부분): 「Ⓗ 가 안 사던 날」 **0일**. Ⓗ 의 시장 갈래(지수 눌린 날)와 같은 날에 뜬다 → 자리만 다툰다
- 빈 날을 연 칸은 **제 낙폭**을 보는 것뿐: 의료·정밀기기·낙폭60↓ (126%), 소형 운송장비·부품·낙120↓ (105% · 새 날 84 · 문턱 9변형 중 8 ✅)
- 「새 날 0」인데 +5% 인 칸(소형 섹터대비 위20%·선물20↓)은 같은 날 더 나은 종목으로 바꿔 탄 것 — 흔들면 두 변형이 바탕으로 떨어진다. 약하다

**둘째 (Q-32 · 중형·대형): 얹으면 낙폭 -38% 는 장치가 아니라 규칙의 행동이었다**
- 칸이 제 자료에서 낸 상대갭(20분위 = -0.68)은 대형엔 너무 느슨하다. Ⓗ 사건이 합쳐지자 「후보 3개 미만이라 건너뛰던 날」이 열려 칸 거래가 66건 → 188건
- 시뮬엔 중복금지가 없어(266차에서 잰 적만 있다) 계속 떨어지는 137310 을 2023년 3~6월에 열 번 넘게 반복 매수했다 (매번 -36~-43%)
- 갭무름을 빼고 Ⓗ 의 -3.5 를 대형에도 쓰면 275.9M · -10.7% · 341 → 셋 다 ✅ (걷기는 Q-33 에서)

**How to apply:**
- OR 후보는 **새 날 수**를 먼저 본다. 0 이면 재료가 Ⓗ 와 같은 것이다 — 다른 재료(제 낙폭·수급·재무 변화)를 찾는다
- 칸이 낸 상대갭을 Ⓗ 위에 얹을 땐 그대로 쓰지 않는다 — Ⓗ 의 -3.5 또는 더 빡빡한 분위(5·10)로 견준다
- 「얹으면 거래가 3배로 는다」는 최소후보 3 문턱이 열린 것이다 — 새 거래 목록(기록=)을 결과% 순으로 찍어 반복 매수를 본다
- 실전 record_pick 에 중복 보유 방지가 있는지 확인한다 (시뮬엔 없다)
