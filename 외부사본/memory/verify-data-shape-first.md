자료 파일의 **필드명을 짐작으로 쓰다가** 2026-09-04 하루에 네 번 틀렸다.

```
dart-daily    "공시"/"stock_code"로 짐작   → 실제는 "챙길공시"·"그밖의공시" / "종목코드"·"공시명"
              ⇒ 4,104일을 읽고 **0건**을 파싱하고도 그냥 진행해
                「공시는 값을 못 한다」는 **틀린 결론**을 낼 뻔했다
dart-capital  "bddd"만 봄                → 갈래마다 날짜 필드가 다르다(bddd·aq_dd·…)
              ⇒ **유상증자 5,050건**을 통째로 놓쳤다
              게다가 갈래 목록에서 **자사주처분 3,682건**도 빠뜨렸다
              ⇒ 이걸 넣으니 「조건 추가가 처음으로 이겼다」는 결론이 **뒤집혔다**
krx-daily     "시가총액"으로 짐작          → 실제는 **"시총"**
index-daily   시가가 있다고 가정           → **종가·등락률만** 있다 (지수 갭 계산 불가)
```

**Why:** 필드명은 만든 사람 마음이고, 같은 폴더 안에서도 **갈래마다 구조가 다르다**.
그리고 파싱이 0건이어도 코드는 조용히 돌아가서, **틀린 결론까지 그대로 간다.**

**How to apply:**
1. 새 자료를 처음 쓰면 **반드시** `python scripts/peek.py data/<폴더> --전부`를 먼저
   돌린다. 최신 파일 구조 + **여러 파일을 훑어 구조가 몇 갈래인지**까지 찍어준다.
   ("목록 안쪽 구조 갈래 5가지 ⚠️ 한 갈래만 보고 파싱하면 놓친다"를 이걸로 잡았다)
2. 파싱 결과가 **0건이면 경고가 아니라 멈춤**으로 짠다. 파일은 있는데 0건이면
   필드명이 틀린 것이다. sweep2_lab에 그렇게 넣어뒀다.
3. **갈래 하나가 통째로 0건이어도 알린다.** 유상증자를 그렇게 놓쳤다.
