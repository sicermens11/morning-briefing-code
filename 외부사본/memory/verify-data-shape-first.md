```
dart-daily    "공시"/"stock_code"로 짐작   → 실제는 "챙길공시"·"그밖의공시" / "종목코드"·"공시명"
              ⇒ 4,104일을 읽고 **0건**을 파싱하고도 그냥 진행해
                「공시는 값을 못 한다」는 **틀린 결론**을 낼 뻔했다
dart-capital  "bddd"만 봄                → 갈래마다 날짜 필드가 다르다(bddd·aq_dd·…)
              ⇒ **유상증자 5,050건**을 통째로 놓쳤다
              게다가 갈래 목록에서 **자사주처분 3,682건**도 빠뜨렸다
              ⇒ 이걸 넣으니 「조건 추가가 처음으로 이겼다」는 결론이 **뒤집혔다**
krx-daily     "시가총액"으로 짐작          → 실제는 **"시총"**
index-daily   시가가 있다고 가정           → **종가·등락률만** 있다 (지수 갭 계산 불가)
```

## ⭐ **한 겹 더 들어가 있는 파일** (2026-09-19 · 가장 오래 못 잡은 것)

```
stock-base.json = {"받은날":.., "종목수":.., "종목":{코드:{이름,시장,…}}}

판 13개가 **겉을 돌았다** — 키가 셋(받은날·종목수·종목)뿐인데
  for c2, v2 in _sb.items():
      if isinstance(v2, dict) and v2.get("시장"):   ← 아무것도 안 걸린다
⇒ 시장표가 **텅 빈 채** 돌았고, 「닥이 들었나」가 **늘 거짓**이 되어
   코스닥 1,823종목(전체의 66%)이 **코스피 지수로** 시장낙폭·변동성을 봤다.
   실전(record_pick)은 O._기본() 이 ["종목"]을 꺼내 **제대로 보고 있었다**
   ⇒ 시험과 실전이 **서로 다른 지수**를 보며 규칙 둘(㉢·㉤)을 검증했다
```

**Why:** 필드명은 만든 사람 마음이고, 같은 폴더 안에서도 **갈래마다 구조가 다르다**.
그리고 **빈 표는 오류를 안 낸다.** `.get()` 은 None 을 돌려주고, `or ""` 가 그걸 삼키고,
`"닥" in ""` 은 조용히 False 다 — 파싱 0건보다 더 안 보인다.
같은 블록을 새 판에 **복사해 넣을 때** 함께 복사된다 (combo_lab 은 원래 맞았는데 13개가 틀렸다).

**How to apply:**
1. 새 자료를 처음 쓰면 **반드시** `python scripts/peek.py data/<폴더> --전부`를 먼저
   돌린다. 최신 파일 구조 + **여러 파일을 훑어 구조가 몇 갈래인지**까지 찍어준다.
2. 파싱 결과가 **0건이면 경고가 아니라 멈춤**으로 짠다. 파일은 있는데 0건이면
   필드명이 틀린 것이다. sweep2_lab에 그렇게 넣어뒀다.
3. **갈래 하나가 통째로 0건이어도 알린다.** 유상증자를 그렇게 놓쳤다.
4. ⭐ **찾아보기 표(lookup)를 만들면 그 자리에서 크기를 찍는다.**
   `print(f"시장표 — {len(시장표):,}종목 (코스닥 {…:,})")` 한 줄이면 20일을 아낀다.
   빈 표는 터지지 않고 **틀린 답을 끝까지 들고 간다.**
5. ⭐ **같은 블록이 여러 판에 복사돼 있으면 `grep -rn` 으로 전부 고친다.**
   하나만 고치면 나머지 12개가 계속 틀린 값을 낸다.
6. ⭐ **시험이 실전과 같은 값을 보는지 따로 확인한다.** 이번엔 실전이 맞고 시험이 틀렸다.
