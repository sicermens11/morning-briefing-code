검사기(`scripts/rule_align.py`)는 **목록에 적힌 파일만** 본다.
목록에 없으면 그 파일이 옛 규칙을 손으로 적고 있어도 **영영 ✅ 로 통과**한다.

2026-09-11 하루에 같은 종류의 구멍을 **두 번** 만났다.
```
오전  정규식이 못 찾으면 None -> 비교에서 빠져 통과
      「볼린저 문턱」 시험 칸이 실제로 비어 있었다
오후  `how_often.py` 가 검사 목록(_살아있는)에 **아예 없었다**
      그래서 혼자 옛 규칙(섹터·시장 없음 · 시총 하한 500억)으로
      화면에 숫자를 내보내고 있었다
```

**Why:** 검사기를 믿는 순간, 검사기의 **사각지대가 곧 사고 지점**이 된다.
「✅ 다 맞다」는 「내가 본 것 중에는」이라는 뜻이다.

**How to apply:**
- 규칙 값을 읽는 파일을 새로 만들거나 되살리면 **그 자리에서** `_살아있는` 에 넣는다
- 검사기 결과를 보고할 때 **무엇을 봤는지(목록)를 같이** 찍는다 — [[claim-full-coverage-only-after-diff]]
- 「못 찾음」은 통과가 아니라 **실패**로 센다
- 정규식 감시는 **주석을 지운 사본**으로 본다. 안 그러면 고쳤다는 설명이
  걸려 가짜 경보가 되고, 가짜가 쌓이면 진짜를 안 보게 된다
