**사용자 (2026-09-23):** 「내가 말한 걸 너가 좁게 이해하거나, 전체 중 일부만 확인하고 됐다고 하는 경우가 있어서 문제가 발생하는 것 같은데, 방지·예방할 수 있는 방법 없나?」

**Why — 이번 주에 난 자리:**
- 「대형주는 대형 자료로」 → 신호만 새로 냈다. 문·자리·파는 규칙은 소형 그대로 → 이틀 연속 「절반」 [[rule-has-eight-layers]]
- 「재료 전부」 → 내가 11개 고름. 「규모·섹터 등등」 → 대형만 짬. **「등등」을 안 읽었다**
- 판이 돌았다 = 됐다로 침 → B12 산 것 0 · 걷기가 자기 자신과 견줌 → 결과를 열어 읽고서야 알았다
- 검사기가 Q절만 봐서 풀의 소형 문을 못 봤다 [[pool-gate-is-a-small-cap-rule]]

**How to apply — 다섯 장치 (다짐이 아니라 동작):**
1. **되풀이 확인**: 조각이 둘 이상이거나 「전부·등등·다양하게·모두」가 들어 있으면, 시작 전에 「이렇게 알아들었다: ①…②…③…」 + **「빠진 것 있나?」** 한 줄. 한 턴 든다. 사용자가 번호(①②③)를 주면 빠진 번호가 바로 보인다
2. **전체를 코드로 센 뒤 시작**: 「전부」는 내가 고르지 않는다. 원본(재료 대장 · 사건 칸 · 갈래 목록)에서 개수를 찍고 「N 중 N」이 보이게 [[claim-full-coverage-only-after-diff]] [[ledger-answers-coverage]]
3. **완료 보고엔 「안 한 것」 칸 의무**: 한 것 / **안 한 것** / 무엇으로 확인했나. 셋이 없으면 완료 보고가 아니다
4. **결과를 열어 읽기 전엔 「됐다」 금지**: 요약 줄이 아니라 항목별 숫자. 0 · 같은 값 · 갑자기 −38% 같은 이상을 먼저 찾는다 [[finish-data-before-concluding]]
5. **검사기를 늘린다**: 사람이 잊는 건 코드가 잡는다 (막개 ④가 두 번 잡았다). 여덟 층 표 없으면 ❌ · 풀 만드는 코드도 검사 · 재료 개수 머리에 찍기
