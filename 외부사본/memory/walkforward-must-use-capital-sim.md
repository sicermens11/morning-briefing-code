걷기검증(과거로 정하고 미래로 시험)을 **날짜 단위 평균 수익**으로 하면 안 된다.
**자본 시뮬**로 다시 해야 한다. 둘이 어긋나면 **자본 시뮬을 믿는다.**

```
같은 신호 · 같은 걷기검증인데
  61차  날짜 단위 평균 수익  →  +9.98% · **8/8해** → 통과라고 봤다
  72차  자본 시뮬           →  **+5.65% · 4/9** → 무너졌다
```

**Why:** 2026-09-03에 겪었다. 평균 수익은 모든 거래를 **같은 무게**로 센다.
실제 돈은 **초기에 깎이면 복리로 회복이 안 된다.** 걷기검증은 초기 연도에
학습 표본이 적어 문턱이 흔들리는데, 그때 손실이 나면 뒤에서 아무리 잘해도 못 따라잡는다.
[[avg-return-is-not-money]]의 두 번째 사례다 (첫 번째는 60차 — 「평균 +21%」 신호가
자본으로는 10.4년에 500만 -> 630만원이었다).

**How to apply:**
- 평균 수익·승률·연도별 = **후보를 거르는 1차 관문**
- 자본 시뮬 + 걷기검증 = **최종 판정**
- 「걷기검증 통과」라고 말하기 전에 **어느 방식으로 쟀는지** 먼저 밝힌다
- 관련: [[avg-return-is-not-money]] · [[signal-financial-quality-dip]] · [[evidence-before-rules]]
