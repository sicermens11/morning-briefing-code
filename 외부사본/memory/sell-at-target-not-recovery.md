빠진 걸 사는 규칙([[buy-dips-not-rallies]])의 **매도 쪽 짝은 「올라온 걸 판다」가 아니다.**
2026-09-07 자본 시뮬(후보 46,564건 · 10.4년 · 전체 기간과 2025·26 제외 둘 다):

```
목표가(+15%/+40%)까지 기다림   6,432만   낙폭 -3.3%   ← 지금 쓰는 것
20일선 위로 오면 판다          3,340만   낙폭 -8.8%   (-48%)
```
돈만 반 나는 게 아니라 **낙폭까지 2.7배 나빠졌다.**

**Why:** 20일선 회복은 반등의 **시작**이지 끝이 아니다. 우리 규칙의 이득은
그 뒤 구간에서 나온다. 「상태로 팔면 시장이 알아서 때를 알려줄 것」이라는
직관이 정확히 반대였다.

**How to apply:** 청산 시점을 「날짜가 절대적이라 어색하다」는 이유로 상태 조건으로
바꾸자는 제안이 다시 나오면, 이 결과를 먼저 보여준다. 바꿀 거면
**날짜를 조정**하는 쪽(40/90일 값 자체)이지 조건 종류를 바꾸는 쪽이 아니다.

⚠️ 같이 배운 것: 「20일선 위」와 「볼린저 0 위」는 **같은 조건이다**
(볼린저 0 = 종가가 20일평균과 같음). 다른 시험인 줄 알고 둘 다 돌려
원 단위까지 똑같은 결과를 받고서야 알았다 — 신호를 추가하기 전에
**이미 있는 신호와 수학적으로 같은지** 먼저 따진다. [[dont-add-conditions]]
