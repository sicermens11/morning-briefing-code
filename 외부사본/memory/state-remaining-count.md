**진행 상황을 말할 때는 「남은 것 N개」를 숫자로 적는다.** 다 했으면 "남은 것 0개"라고 쓴다.

2026-09-01에 안건 넷을 하기로 해놓고 **둘만 하고 "정리 끝났습니다"**라고 보고했다. 사용자가 알아채고 물었다: *"이거 네개 하기로 했는데 다 한거야?"* 그리고 한 번 더: ***"이러면 내가 널 어떻게 믿나? 끝났다면서 안건이 남아있잖아."***

**Why:** 나는 "지금까지 한 것"을 요약했는데, 사용자는 그걸 **"다 했다"**로 읽는다. 요약과 완료 보고는 글꼴이 같아서 구분이 안 된다. 그리고 이 시스템은 하루에 안건이 여러 개 열리므로, **내가 안 세면 아무도 안 센다.** 한 번 이러면 다음 보고도 못 믿게 된다 — 잃는 것이 시간이 아니라 **신뢰**다.

**How to apply:**
- **끝맺는 말에 반드시 숫자를 넣는다.** "남은 것 0개" / "남은 것 2개 — ③재무취약 ④놓침축". 형용사(대부분·거의·일단)로 얼버무리지 않는다.
- **여러 개를 하기로 했으면 목록을 그대로 들고 간다.** 중간에 새 발견이 나와도 원래 목록을 지우지 않는다 — 2026-09-01에 점수 분석에 빠져 ③④를 잊었다.
- **기각도 완료다.** 안 하기로 정했으면 "기각 — 사유"로 닫고 남은 것에서 뺀다. 열어둔 채 넘어가지 않는다.
- ⚠️ **긴 작업 중간의 요약은 "여기까지 한 것"이라고 못박는다.** 그 말이 없으면 완료로 읽힌다.
- 관련: [[record-decisions-and-tasks]]의 "끝난 일은 그 자리에서 닫는다"와 짝이다. 그건 파일에 남기는 규칙이고, 이건 **말할 때** 지키는 규칙이다.
