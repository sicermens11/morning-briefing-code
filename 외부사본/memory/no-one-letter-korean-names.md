시험 스크립트에서 **한 글자 한글 이름**(`비` `묶` `날` `골` `평`)을 for 문의
반복 변수로 쓰지 않는다. 자료를 담는 딕셔너리 이름과 충돌한다.

```
비  = 시가/종가 비율 딕셔너리     묶 = 날짜별 사건 딕셔너리
날  = 거래일 목록               종계·자리·갭표 = 종목별 자료
⇒ for 종, 비 in ... / for 비 in (0.26, 0.5) / c, 날 = ... 이 전부 덮어쓴다
```

**Why:** 2026-09-07 하루에 **다섯 번** 났다. 파이썬은 경고를 안 주고, 프로그램은
정상 종료하며, 표도 그럴듯하게 나온다. 「산 것 0건」이나 「모든 줄이 같은 값」으로만
드러난다. **그날 오전에 문서화까지 해놓고 오후에 또 냈다** — 주석으로는 안 막힌다.

**How to apply:** 반복 변수는 두 글자 이상으로 (`비용값` `섹묶음` `날짜2` `주수` `종목수`).
그리고 **훑기 직전에 실행 시 확인**을 넣는다 — 이게 제일 확실하다:
```python
assert isinstance(날, list) and len(날) > 1000, "거래일 목록이 망가졌다"
assert isinstance(비, dict), "`비`가 덮어써졌다"
```
정적 검사(정규식)는 만들었다가 뺐다 — `[d for d in 날 if ...]` 같은 정상 코드를
잡아서 헛경보 15건이 났다. [[lab-results-must-persist]]와 함께
새 시험 스크립트를 만들 때 [[verify-data-shape-first]] 다음으로 확인할 것.
