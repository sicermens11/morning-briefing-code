**저장소에 대한 사실 주장은 같은 턴에 도구 호출로 확인한 뒤에만 한다.**
「없다 · 안 했다 · 처음이다 · 이게 원인이다」는 특히 그렇다.

**Why:** 2026-09-28 하루에 **일곱 번** 말을 뒤집었다. 일곱 다 같은 꼴이었다 —
기억으로 말하고, 곧바로 파일을 열어 보니 틀렸다. 자료엔 처음부터 답이 있었다.

| 내가 한 말 | 사실 |
|---|---|
| 「판 47분 중 42분이 밑준비」 | 아니었다 |
| 「도전자들이 18분 먹는다」 | 재는 장치가 잘못 귀속한 것 |
| 「대형주 문을 열까가 결정거리」 | **이미 열려 있었다** (27cd314) |
| 「휴장일에 브리핑이 돌았다」 | 브리핑은 멈췄다. 다른 둘이 돌았다 |
| 「대형 전용 규칙을 한 번도 안 찾았다」 | **연휴에 찾았다** (B73·B82·B87·BAND5) |
| 「수익률만 봤다」 | 끝 자산은 처음부터 돈이었다 |
| 「EntryCheck1220 이 정리 안 됐다」 | 8/28 에 이유를 적고 끈 것 |

사용자: 「아니 왜 자꾸 번복이 일어나지? 헛돌고 있는거 아니야? 세션을 바꿔야하나?」
세션을 바꾼다고 안 고쳐진다 — **새 세션은 맥락이 더 적다.** 고칠 것은 습관과 장치다.

**How to apply:**
· 「없다 / 안 했다 / 처음이다」를 쓰기 전에 **반드시** `ls`·`grep`·`git log` 를 같은 턴에 돌린다
· 원인을 말하기 전에 **재현하거나 재 본다** (악재 캐시·때 지도 둘 다 재 보고서야 알았다)
· 되풀이해 틀리는 물음은 **대장을 만든다** — `rule_ledger.py`(무엇이 갈라졌나·뭘 쟀나) ·
  `material_ledger.py`(안 잰 재료) · `lab_ledger.py`(기록 안 된 시험) · `check_lab_result.py`(결과 검산)
· 재는 장치는 **스스로 검산**하게 만든다 (때 지도가 「찍힌 합 N분」을 같이 낸다)
