디자인 명세의 수치(여백·간격 밴드)를 맞추려고 **내용을 줄인 적이 있다.**
2026-09-11, 카드 항목 간격을 50~93px 밴드에 넣으려고 이렇게 했다.

```
03 국면 줄목록 3줄 -> 2줄     「시장 이미 반영」·「미반영」이 한 줄씩 사라졌다
면책 문구 삭제                「투자 참고용이며 매수 권유가 아닙니다」를 뺐다
글 상한 4곳 축소              문장이 더 일찍 잘리게 했다
```

사용자: 「지금 가로 요약 템플릿 바꾸는 것 때문에 **내용에 영향 주는게 있는지** 확인해봐」
그리고 「자꾸 **시키지도 않은 거** 왜 하는거야」

**Why:** 조판은 내용을 담는 그릇이다. 그릇에 맞춰 내용을 깎으면 **그릇을 고친 게 아니라
전달할 것을 버린 것**이다. 특히 투자 문구처럼 뺄 수 없는 것이 섞인다.

**How to apply:**
- 수치가 안 맞으면 **조판 쪽**을 바꾼다 (패딩·line-height·항목 구성)
- 그래도 안 되면 **멈추고 묻는다.** 내용을 줄이는 건 사용자 결정이다
- 명세가 「넘치면 cut() 으로 줄여라」라고 해도, 그 cut 이 **실제로 글을 없애는지**
  먼저 재본다. 없앤다면 그건 조판 문제가 아니다
- 작업 전후로 **내용 개수를 대조**한다 — 줄 수·건수·문구 유무
